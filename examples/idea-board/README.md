# 다음 아이디어

처음 만든 파란색 아이디어 보드를 독립 프로젝트로 복원한 버전이다. index.html의 화면과 초기 카드 3개, 추가·삭제·좋아요·합계 동작을 그대로 보존한다.

서버 설치 없이 Browser pane의 content에 실제 index.html을 넣어 공개한다. 새 turn에서 창이 접히면 기존 idea-board pane을 다시 보여줄 수 있다. 원문이 바뀌었으면 읽고 같은 ID로 갱신한다.

현재 데이터는 화면 내 상태다. 새로고침하면 추가/좋아요 등 조작이 초기화되고 다른 관객과 공유되지 않는다. 실제 저장과 공유 기능은 아직 구현하지 않았다.

해볼 요청:

- “원래 아이디어 보드를 보여줘.”
- “현재 되는 것과 남은 작업을 보여줘.”
- “아이디어를 새로고침해도 유지하려면 어떤 저장 방식이 좋을지 선택하게 해줘. 선택 전에는 구현하지 마.”
- “카드를 지금 형태와 컴팩트 목록형으로 비교해서 고르게 해줘.”
