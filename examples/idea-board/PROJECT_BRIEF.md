# 다음 아이디어 — 원본 아이디어 보드

Pado 초기에 만든 파란색 아이디어 보드를 별도 프로젝트로 보존한다. 첫 화면과 기존 동작은 바꾸지 않는다.

현재 범위: 예시 아이디어 3개, 카드 추가·삭제, 좋아요 토글, 합계, 반응형 화면. index.html 하나가 원본이다. Browser의 격리된 정적 HTML 미리보기로 동작한다.

추가·삭제·좋아요는 해당 브라우저 화면에만 반영된다. 서버 저장, 새로고침 후 유지, 관객 간 데이터 동기화는 없다. Pado의 pane 공유와 앱 데이터 공유를 혼동하지 않는다.

독립 프로젝트에서 실제 저장·공유·투표 정책 등을 선택하고 확장할 수 있다. 사용자가 요청하기 전에는 원본 보드를 새로운 앱으로 바꾸지 않는다.
