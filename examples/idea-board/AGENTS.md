# 아이디어 보드 작업 규칙

- PROJECT_BRIEF.md와 docs/TASKS.md를 기준으로 한다. index.html은 초기 보드의 원본 복사본이며 사용자 요청 없이 재설계하지 않는다.
- 현재 정적 Browser다. index.html 실제 내용을 Browser content로 공개하고 pane ID는 idea-board를 재사용한다. 코드를 읽거나 고쳤다는 이유만으로 File/Terminal을 열지 않는다.
- 카드 추가/삭제/좋아요는 화면 내 상태다. 서버 저장이나 여러 사용자의 공유 데이터라고 설명하지 않는다. 새로고침하면 초기화된다.
- 작업 목록은 실제 docs/TASKS.md로 Tasks에 표시한다. 미래 작업은 완료처럼 표시하지 않는다. 다음 작업은 사용자 결정 후 [>] 하나만 지정한다.
- 데이터 공유·투표·삭제 권한은 사용자에게 먼저 결정받는다. 화면 비교는 시각적 Input, 정책 검토는 Docs, 구현 결과 검토는 Browser/Review를 필요한 순간에 쓴다.
- 앱 실행이나 검사 스크립트가 필요하면 credential-free AppRuntime에서만 실행한다. 호스트·다른 프로젝트·인증정보에 접근하지 않는다.
- 기존 공개 데이터나 사용자 파일을 임의로 삭제하지 않는다. 원본 유지 여부가 달라지는 큰 변경은 명시한다.
