# 해커톤 데스크 — 임시 시연 프로젝트

## 목적

해커톤 참가자가 팀을 등록하고 운영진에게 질문을 남기는 작은 운영 도구다. Pado에서 실제 프로젝트를 발전시키며 결과·문서·선택을 검토할 수 있는 베이스로 사용한다.

2026-09-19 사용자가 임시 베이스로 승인했다. **최종 시연 앱을 확정한 것이 아니며 나중에 교체할 수 있다.** Pado 본체는 이 도메인에 의존하지 않는다.

## 첫 번째 사용 가능한 흐름

- 팀 이름과 만들고 있는 프로젝트 한 줄을 등록한다.
- 등록된 팀을 선택하고 분야·제목·내용을 입력해 질문을 접수한다.
- 다른 참가자가 같은 팀·질문 목록을 보고, 새로고침과 서버 재시작 후에도 결과가 남는다.
- 빈 입력, 중복 팀 이름, 존재하지 않는 팀을 서버에서 검증한다.
- 데스크톱과 모바일에서 실제 폼을 사용할 수 있다.

## 범위와 가정

- 신뢰된 내부망의 공동 시연용이다. 실제 개인정보·비밀·민감한 질문을 입력하지 않는다.
- 첫 버전은 모든 질문을 공동 열람하며 팀 선택은 인증이 아니다. 진짜 운영자 권한이나 팀 소유권을 주장하지 않는다.
- 운영자 답변, 질문 공개 정책, 중요도, 행사 일정은 후속 사용자 흐름이다. 미완성 기능을 동작하는 것처럼 표시하지 않는다.
- 외부 API·로그인·결제·공개 배포는 하지 않는다.
- React + TypeScript + Vite, Node HTTP + SQLite를 사용하고 Pado의 인증 없는 앱 컨테이너 안에서 실행한다.
- 실제 문서와 작업 목록을 유지하되 파일이 있다는 이유로 pane을 자동 생성하지 않는다.

## 교체 가능성

버전 관리용 원본은 `examples/hackathon-ops`, 에이전트가 발전시킬 작업본은 `/workspace/hackathon-ops`다. 기존 workspace 파일과 Pado의 원본 브리프를 덮어쓰지 않는다. 폐기·데이터 삭제·다른 앱으로 전환은 별도 사용자 결정이다.
