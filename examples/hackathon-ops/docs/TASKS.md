# 사용자 흐름

이 앱은 임시 베이스다. [>]로 선택된 다음 작업은 현재 없다. 대기 목록 순서는 자동 실행 지시가 아니다.

- [x] **팀을 등록하고 질문을 접수한다.** 팀 이름·프로젝트 소개를 저장하고 해당 팀의 질문을 등록한다. 중복·빈 입력을 거부하고, 다른 브라우저·새로고침·서버 재시작에서도 결과가 보인다. 모바일 폼, 오류 메시지, 키보드 레이블과 API 테스트를 검증했다.
- [ ] **참가자가 질문 공개 범위를 이해하고 선택한다.** 전체 공개/팀별 공개/운영진만 공개 중 실제 운영 정책을 먼저 정한다. 접근 주체를 인증할 방법 없이 비공개라는 표시만 붙이지 않는다. 승인된 정책의 허용·거부 테스트가 통과해야 완료다.
- [ ] **운영자가 답변하고 참가자가 답변을 확인한다.** 운영자 권한과 팀 식별 방식을 결정한 뒤 답변·처리 상태를 저장한다. 새 브라우저에서도 답변이 보이고 비권한 요청은 거부된다.
- [ ] **운영자가 중요한 질문부터 처리한다.** 긴급도/대기 시간/참가자 공감 중 정렬 기준을 선택한다. 동률·중복 공감·상태 전환의 기대 순서와 실제 결과가 일치한다.
- [ ] **참가자가 행사 일정과 공지를 확인한다.** 실제 일정과 수정 주체를 받은 뒤 구현한다. 모바일에서도 시각·변경 여부가 명확하고 오래된 공지가 현재 안내로 오인되지 않는다.
- [~] **실제 행사에 공개한다.** 시연 주제 확정, 인증·권한·개인정보 정책, 호스팅과 복구 절차를 별도로 승인받기 전에는 진행하지 않는다.
