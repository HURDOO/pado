# 결정 기록

## D1 · 2026-09-19 · 임시·독립 베이스

사용자가 해커톤 운영 도구를 우선 만들되 나중에 바꿀 수 있다고 지정했다. Pado 본체와 별도 폴더·별도 DB로 둔다. 기존 workspace 산출물은 보존하고 전환 시에도 자동 삭제하지 않는다.

## D2 · 첫 흐름의 공동 열람 한계

최초 버전은 신뢰된 내부망 공동 시연용으로 팀 등록과 질문 접수만 제공한다. 팀 선택은 작성 맥락이지 로그인이나 소유권이 아니다. 모든 질문이 공개된다는 안내를 입력 전에 보인다. 실제 참가자 정보나 민감한 질문은 수집하지 않는다.

**미정:** 전체 공개를 유지할지, 팀별/운영진 공개를 도입할지. 비공개 도입은 인증·권한 설계까지 함께 결정해야 한다. 사용자 결정 없이 현재 가정을 최종 운영 정책으로 굳히지 않는다.

## D3 · SQLite와 예시 데이터

기존 검증된 React/Vite/Node 앱 패턴과 Node 24 내장 SQLite를 사용한다. 팀 이름은 공백 정리·NFKC·소문자 정규화로 중복을 방지하며 질문은 존재하는 팀을 참조한다. 로컬 DB로 재시작 후 데이터를 유지한다. 예시는 자동 주입하지 않고 명시적인 seed:demo로만 추가하며 모두 가상 예시로 표시한다.

**미정:** 운영자 답변 권한, 질문 우선순위 기준, 행사 일정. TASKS에 실제 후속 흐름과 완료 조건으로 남긴다.
