# 해커톤 데스크 작업 규칙

- PROJECT_BRIEF.md를 기준으로 한다. 임시 베이스이며 최종 시연 주제가 아니다. Pado 본체에 해커톤 전용 로직을 추가하지 않는다.
- README와 docs/TASKS.md에서 실제 구현·검증 상태를 읽고 작업한다. 선택된 다음 작업은 [>] 하나만 허용한다. 브리프는 보존한다.
- React + TypeScript + Vite / Node 24 HTTP + SQLite. 기존 앱 컨테이너의 npm 도구를 사용한다. 설치·앱·테스트는 인증 없는 AppRuntime에서만 실행한다.
- 실제 데이터는 data/desk.sqlite다. 초기화·삭제·덮어쓰기 금지. 예시는 seed:demo 명령으로 명시적으로만 추가한다.
- 모든 질문은 현재 공동 열람이다. 팀 선택을 인증으로 취급하지 않는다. 비밀값·개인 연락처를 받지 않는다.
- 공개 범위, 운영자 권한, 우선순위 기준은 사용자 결정이 필요하다. 현재 미구현을 완성된 것처럼 표시하지 않는다.
- API는 상대 경로, 외부 CDN·서비스 의존성 없음. 공개 배포하지 않는다. client/만 Vite 공개 루트다.
- 변경 후 npm run check, 데스크톱·모바일 실제 브라우저 폼·오류·공유 조회를 검증한다. 체크가 실패하면 완료로 표시하지 않는다.
- 파일 읽기/작성만으로 pane을 만들지 않는다. 단순 답변은 TUI, 작업 목록·진행·남은 일·다음 작업 검토는 Tasks, 정책·결정 기록 검토는 Docs, 실제 선택은 Input, 동작 검토는 Browser를 필요한 순간에 사용한다. Tasks는 실제 docs/TASKS.md를 읽어 공개하고 상태가 바뀌면 같은 pane을 갱신한다. 종류별 pane을 모두 만드는 시연 대본은 금지한다.
