# 개발자 블로그 작업

Pado 시연과 실제 확장을 위한 베이스. 예시 콘텐츠이며 최종 디자인이나 게시 정책은 바뀔 수 있다.

- [x] 글 목록·상세·검색·태그 필터와 오류 화면을 만들고 실제 서버·브라우저에서 검증한다.
- [ ] RSS와 구독 링크를 추가한다. RSS에 본문 전체를 넣을지는 먼저 결정한다.
- [ ] 글 목록의 행/카드형 레이아웃을 비교하고 독서 흐름에 맞게 선택한다.
- [ ] 초안과 발행 글의 구분을 설계한다. 현재 content의 모든 글은 공개된다.
- [~] 댓글: 익명/로그인, 보관·관리 정책을 정하기 전까지 보류한다.
- [~] 공개 배포와 관리자 편집기: 인증과 운영 경계를 검토한 뒤 진행한다.

선택된 다음 작업 없음. 대기 순서는 우선순위가 아니다. 사용자 지시 전에는 보류 항목을 재개하지 않는다.

검증(2026-09-19): 인증 없는 앱 컨테이너에서 문법 검사·HTTP 테스트 통과. Chromium 1280/390/320px에서 검색·태그·빈 결과·필터 초기화·상세·직접 URL·새로고침·없는 글·가로 넘침을 확인했다. Markdown의 script 문자열이 실행되지 않고 텍스트로 표시됨을 확인했다. 실기기 Android와 공개 운영은 검증하지 않았다.
