# 현재 결정과 열린 질문

- 첫 버전은 독자용 읽기 화면에 집중한다. 글 관리는 프로젝트 파일과 에이전트로 한다.
- 외부 의존성과 로그인을 두지 않는 작은 Node 앱이다. 콘텐츠는 Markdown과 JSON에 보관한다.
- 샘플 글의 예시 표시는 유지한다. 실제 저자가 작성한 경험이나 측정 결과로 바꾸지 않는다.
- 원시 HTML은 실행하지 않는다. 본문은 텍스트 중심으로 표시한다.

아직 정하지 않은 것:

1. 목록에서 많은 제목을 빠르게 훑을지, 각 글의 소개를 넓게 보여줄지.
2. RSS에 전체 글을 넣을지 요약만 제공할지.
3. 댓글을 받을지, 받는다면 익명 허용과 관리 방식은 무엇인지.
4. 초안·예약 발행·웹 편집기가 필요한지.

선택이 필요한 작업을 요청받으면 적절한 Input을 통해 실제 답변을 기다린다.
