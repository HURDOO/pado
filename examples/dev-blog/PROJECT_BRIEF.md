# 작은 기록 — 개발자 블로그

개발 중 배운 것과 시행착오를 짧은 글로 남기는 읽기 중심 블로그. Pado에서 발전시킬 수 있는 교체 가능한 베이스 프로젝트다.

첫 범위: Markdown 글 목록·상세, 제목/요약/태그 검색, 태그 필터, 모바일 읽기, 없는 글과 빈 검색 결과 처리. 글 3편은 명시적인 예시 콘텐츠다. 저자의 실제 경험이나 사용자 연구 자료로 취급하지 않는다.

글 원본은 content/*.md, 목록 메타데이터는 content/posts.json. Node 24 서버가 제공하며 외부 서비스·CDN·DB·로그인은 없다. 공개 웹 편집기, 댓글, 조회 수, RSS, 공개 배포는 아직 포함하지 않는다.

다음 확장 후보는 docs/TASKS.md에 둔다. 게시 정책·댓글·글 목록 레이아웃 등 선택이 필요한 순간에는 사용자가 결정한다.
