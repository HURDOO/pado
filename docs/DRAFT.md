# 2026-09-18 22시 초안

> 이 문서는 22시의 headless/커스텀 채팅 초안 기록이다. 이후 사용자 요청으로 Agent pane을 **원본 Antigravity TUI**로 교체했으며, 현재 구조·사용법·검증 결과는 [TUI 안내](TUI.md)를 따른다. 아래 4개 실제 AI 테스트와 subagent 카드 검증은 이전 구현의 결과다.

## 열어보기

- 내부망 / WireGuard 주소: `http://<LAN_IP>:4173` (실제 내부 IP는 생략, 사용자 요청으로 LAN IP에만 바인딩)
- 닉네임으로 입장 → 현재 결과 확인 → `손들고 참여하기` → 60초 안에 아이디어 제출.
- 별도 관객은 시크릿 창이나 다른 브라우저로 입장. 모바일은 pane 탭으로 전환.
- 관리자: 우측 위 설정에서 `.env`의 `PADO_ADMIN_PASSWORD` 사용. 비밀번호를 채팅에 붙여 넣지 않는다.
- 현재 실행은 실제 Antigravity + production build. 서버를 종료했다면 프로젝트 루트에서 `pnpm start`로 다시 실행.

현재 stage에는 실제 에이전트가 생성한 **다음 아이디어** 보드와 실제 검증 Terminal을 남겼다. 생성 Input에서 파란 테마를 선택한 뒤 `.pado/workspace/demo-board.html`을 만들었다. 아이디어 추가·좋아요 토글·HTML 텍스트 이스케이프, 6가지 viewport, 작은 화면의 키보드 참여와 모션 설정 저장을 직접 브라우저에서 검증했다. 결과 화면은 `test-results/draft/`에 있다.

후속 요청으로 같은 대화에서 안내 문구를 수정하고 실제 검증을 재실행한 뒤 기존 Browser pane을 갱신하는 흐름도 통과했다. 최종 상태는 진행 중인 turn 없이 다음 발언을 받을 수 있는 상태다.

## 구현 범위

실제 에이전트의 작업 파일과 공개 pane을 분리했다. 내부 파일 수정은 화면을 자동으로 열지 않는다. 에이전트가 명시적으로 Docs/Input/Terminal/File/Browser를 열고 닫고 크기·focus를 바꾼다. 공유 stage, 모바일 Focus Mode, 선착순 단일 발언권, 관리자 제어, 실제 subagent 진행 표시를 지원한다.

Input 답변은 실행 중인 에이전트에게 전달된다. 생성 HTML 오류를 감지해 수정 요청을 되돌려 보내며, 관리자 중단은 실제 Docker 컨테이너 종료를 확인한다. 성공한 대화는 다음 turn에서 맥락을 이어 간다.

## 초안의 경계

- 공개 URL 없음. Cloudflare 연결과 공개 프롬프트용 네트워크·인증 정보 격리는 다음 단계다.
- Browser는 독립형 HTML 미리보기다. 각 관객의 조작은 로컬이며 관객 사이의 앱 데이터 저장·공유 기능이 아니다.
- 생성 Input에는 비밀번호/API 키 등 비밀값을 넣지 않는다.
- stage와 대화 맥락은 메모리 상태다. 서버 재시작 시 사라지지만 `.pado/workspace`의 작업 파일은 남는다. 관리자 초기화도 작업 파일을 삭제하지 않는다.
- File pane은 읽기 전용이다. 범용 IDE·장기 저장·공개 배포는 완료 범위에 포함하지 않았다.
